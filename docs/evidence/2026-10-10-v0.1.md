## 可复现命令

在 Ubuntu Bash 的仓库目录中执行系统依赖安装和普通用户构建：

```bash
bash scripts/install_ubuntu_deps.sh
bash scripts/build_runtime.sh
source /opt/ros/jazzy/setup.bash
source "${AEROBASE_RUNTIME:-$HOME/aerobase-runtime}/ros2_ws/install/setup.bash"
bash scripts/doctor.sh --strict --json
bash scripts/check_local.sh
bash scripts/verify_sitl.sh --output .runtime/evidence/text
bash scripts/verify_sitl.sh --monitor-first --monitor-output json --output .runtime/evidence/json
python3 scripts/summarize_evidence.py .runtime/evidence/text/result.json --output .runtime/text-summary.json
python3 scripts/summarize_evidence.py .runtime/evidence/json/result.json --output .runtime/json-summary.json
```

每次验收使用新输出目录，避免覆盖既有日志。源码不匹配时应人工核对或使用新运行目录，获取器不会重置已有检出。

## 结果与范围

WSL2 整合测试的 45 项 Python 检查通过，包含真实 `px4_msgs` 消息类的字段适配检查；脚本语法和 ShellCheck 通过。严格 doctor 的全部环境及运行目录检查通过。非法 `output_format` 启动参数返回非零状态，诊断输出到 stderr。

两次 WSL2 SITL 运行均收到状态、里程计、电池与全局位置消息；Gazebo 列出 X500 模型，节点没有 PX4 控制发布器或命令服务客户端，全程保持未解锁。停止本次启动的 Agent 后，必选流过期，缓存值被遮蔽；重启 Agent 后恢复 connected。JSON 运行额外验证 stdout 为 schema v1 JSON 行，stale 数据为 null。原生 runner 的结果待运行完成后确认。

单流停止的 degraded 行为由单元测试覆盖，未做独立 SITL 故障注入。Gazebo GUI、ARM、实体飞控、实体传感器、真实飞行、Offboard、MAVLink 或其他后端均未在本报告中验收。模拟数据到达和文件诊断通过不表示状态估计有效、可起飞或已取得安全认证。
